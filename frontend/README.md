# Começando com Create React App

Este projeto foi inicializado com [Create React App](https://github.com/facebook/create-react-app).

## Scripts Disponíveis

Na pasta do projeto, você pode executar:

### `npm start`

Roda a aplicação em modo de desenvolvimento.\
Abra [http://localhost:3000](http://localhost:3000) para ver no navegador.

A página recarrega automaticamente quando você faz alterações.\
Erros de lint também podem aparecer no console.

### `npm test`

Inicia o executor de testes em modo interativo (watch).\
Veja a seção sobre [execução de testes](https://facebook.github.io/create-react-app/docs/running-tests) para mais informações.

### `npm run build`

Gera o build de produção na pasta `build`.\
O React é empacotado corretamente no modo de produção e o build é otimizado para melhor desempenho.

Os arquivos são minificados e os nomes incluem hashes.\
Sua aplicação está pronta para ser publicada!

Consulte a seção sobre [deploy](https://facebook.github.io/create-react-app/docs/deployment) para mais informações.

### `npm run eject`

**Atenção: esta é uma operação irreversível. Depois de executar `eject`, não há como voltar!**

Se você não estiver satisfeito com a ferramenta de build e as escolhas de configuração, pode executar `eject` a qualquer momento. Esse comando removerá a dependência única de build do seu projeto.

Em vez disso, todos os arquivos de configuração e dependências transitivas (webpack, Babel, ESLint, etc.) serão copiados diretamente para o seu projeto, dando controle total sobre eles. Todos os comandos, exceto `eject`, continuarão funcionando, mas passarão a apontar para os scripts copiados, permitindo ajustes finos. A partir daqui, é por sua conta.

Você provavelmente nunca precisará usar `eject`. O conjunto de recursos padrão atende bem a implantações pequenas e médias, e você não deve se sentir obrigado a usar este recurso. No entanto, entendemos que esta ferramenta não seria útil se você não pudesse personalizá-la quando estivesse pronto para isso.
